01 / THE BET

Is the problem worth solving?

Rolefit helps job seekers assess fit and tailor applications using verified career history, rather than generating generic, unsupported claims.

CopilotAI value archetype
MediumStrategic confidence
90 daysGo / no-go pilot

Core thesis

A persistent career profile can make job assessments more accurate and tailored CVs faster to create than general-purpose workflows.

What must be proven

Users find the outputs useful (≥80%), accuracy reaches ≥92%, and repeat usage produces measurable benefits.

Principal risk

LinkedIn and general-purpose AI tools can replicate baseline features before Rolefit proves meaningful differentiation.

02 / THE MOAT

What compounds with use?

The strategic differentiator is a Career Knowledge Base that retains verified experience, user corrections and preferences across applications.

8/20Data flywheel score
1/5Weakest loop: network
LinkedInMain competitive threat

How the flywheel works

Better evidence and corrections improve future job-fit analysis and CV generation for the same user. This is user-level personalization, not shared model retraining.

Defensibility score

Only 40% of the possible flywheel score today. The advantage is promising, but unproven.

Strategic test

Do repeat users spend less time re-entering information and correcting AI outputs as their career evidence accumulates?

Kill Switch · Vendor dependency & portability

Anthropic Claude is the primary AI provider, with partial portability and no confirmed automatic provider fallback. Within 48 hours of a material disruption, assess the impact, test an alternative model, isolate provider-specific integration points and validate critical workflows against a small evaluation set.

If Anthropic doubles its pricing, prioritize job-fit assessments and CV tailoring, test an alternative provider and temporarily limit non-essential AI usage. If Anthropic launches a competing product, strengthen differentiation through the evidence-based Career Knowledge Base and user-specific corrections.

03 / THE MARGIN

Can the economics work?

Rolefit is currently a free prototype. The proposed commercial model is a subscription with usage-based add-ons, subject to real-world validation.

Subscription assumptions

40 fit assessments, 10 tailored CV generations and 5 regenerations per month. Optional $4.99 usage pack.

Model mix

Estimated 73% Claude Sonnet and 27% Claude Opus calls. Forecasts are modeled, not observed operating results.

Stress test

At 3× inference cost, projected margin falls to about 27.8%, below the 40% stress-test threshold. Monitor cost per workflow before scaling.

04 / THE CONTRACT

What makes the AI trustworthy?

Evidence-based outputs, visible uncertainty and explicit user approval are the foundation of Rolefit's reliability contract.

≥92%Target accuracy
11Golden Dataset cases
4Adversarial test cases

Reliability requirements

  • Flag unsupported qualifications rather than invent them.
  • Ask for review below 70% confidence or with contradictory evidence.
  • Require approval before modifying verified Career Profile data.

Critical failure mode

Fabricated experience or qualifications appearing in an application. These safeguards are specified, but production reliability remains unverified.

05 / THE GUARDRAILS

How do we scale responsibly?

Rolefit is designed to support decisions, not make irreversible career decisions on the user's behalf.

4Proposed agent roles
70%Low-confidence review trigger
HumanApproval for profile changes

Autonomy boundaries

AI can analyze job descriptions and draft content; it cannot submit job applications or recruiter communications autonomously. Career Profile changes require user approval.

Operating cadence

Real-time incident monitoring, weekly correction reviews, monthly reliability reviews and quarterly governance reviews.

Privacy first

Individual corrections improve the user's own experience. Cross-user network intelligence is a future, opt-in concept—not a deployed capability.
